1) Regex syntax basics
    . --> any characters, for example '.at' match 'cat, rat, bat hat'
    \. --> dot, match '.'

2) Special characters
    \d --> any digit (0-9)
    \D --> any non-digit
    \w --> any alphanumeric (a-z, A-Z, 0-9)
    \W --> any non-alphanumeric
    \s --> any whitespace
    \S --> any non-whitespace

3) Matching Multiple characters
    + Range of digits
        [0-9] --> ranges of digits, from 1 through 9

    + Range of letters
        [a-z] --> any lowercase letter
        [A-Z] --> any uppercase letter

    + Combined ranges
        [a-zA-Z] --> any letters
        [0-9A-Za-z] --> any numbers or letters

    + sets of characters
        [tlc149] --> t, l, c, 1, 4, or 9
        [tlc1-3] --> t, l, c 1, 2, or 3
    
    note: ^ used to negate in range, for exampl [^a-z]: not a to z

4) Quantifiers
    * --> match zero or more instances of previous character
    + --> match one or more instances of previous character
    ? --> match zero or one instances of previous character

5) Custom Quantifiers with {}
    {n} --> match n instances of preceding character, "a{3} matches 'aaa' not 'aaaa' / 'aa'"
    {n,m} --> match between n and m instances of preceding character, "a{2,4} matches 'aa', 'aaa', and 'aaaa', not 'a'"
    {n,} --> match n or more instances of preceding character, "a{2,} matches 'aa', 'aaa' and 'aaaaaa'"

6) Anchors
    ^ --> denote the start of a string, '^hello'
    $ --> denote the end of a string, 'universe$'

7) Alternation 
    cat|dog --> match "cat" or "dog"

8) Compilation Flags
    IGNORECASE --> make the pattern case insensitive
    MULTILINE --> makes ^ and $ match entire lines, instead of entire string 
    DOTALL --> makes the dot character match all character, including new lines
